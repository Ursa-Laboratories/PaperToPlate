# Documentation media

[← Documentation](../README.md)

| Asset | Origin and meaning |
|---|---|
| `paper-to-plate-hero.svg` | Original editable vector artwork in Ursa's Observatory palette. The paper/plate graphic is a conceptual workflow illustration, not a measured result. |
| `valency-path.svg` | Original editable diagram of the literature-to-experiment path. |
| `color-run.webp` | Fifteen-second, time-compressed preview of actual recorded workcell footage from the completed color-mixture run. No generated frames or predicted measurements were inserted. |
| `media-provenance.json` | Source recording and preview hashes, dimensions, timing, and interpretation. |

The animation derives from a 1,211.6-second camera recording; the controller's
run duration is reported separately in the [execution summary](../evidence/color-run-summary.json).
Compression, scaling, and display rendering mean this preview must not be used
for quantitative color analysis. It contains no audio.

The complete source recording remains a local experiment artifact. The small
preview is intentionally included in Git so the README works without a private
media service or a build-machine path.
