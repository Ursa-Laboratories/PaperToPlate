# Project status

[← Documentation](README.md) · [Evidence & evaluation](EVIDENCE.md)

**Snapshot: October 22, 2026.**

## What has been demonstrated

- Paper/text upload, page-linked extraction, typed liquid plans, native CubOS compilation, and offline validation.
- Live Valency Bond retrieval through the app's own OAuth/MCP connection, with preserved source identifiers and query receipts.
- A source-specific Bradford colored-water preparation example, with explicit separation from actual protein quantification.
- A literature-informed RYB screen that reached a recorded physical workcell run: **94 commands, 10 wells, controller-reported success**.
- Camera-specific tip/liquid models, replay inspection, and additional qualitative observations on an operator recording.

The canonical public summary is [Evidence & evaluation](EVIDENCE.md). It separates controller reports from independent measurements and links the scoped vision reports.

## Current development

The question-led interface is being refined into **question → explore papers → choose a method → generate → run**. Work is also improving how the AI uses retrieved literature, handles equipment constraints, and presents evidence.

The demonstrated local workcell includes run recording and final-image capture. Application work may be ahead of the published code; a documentation snapshot is not a claim that every local interface change is released.

## What remains open

- General equipment-aware method selection beyond supported examples.
- More independently reviewed full-method extractions and executable reference protocols.
- Measured liquid-volume accuracy and appropriate scientific readouts.
- Calibrated color comparisons and iterative experiment selection.
- Independent, run-level validation of vision-based error detection.

## Research materials

The repository retains source-linked extraction work, candidate catalogues, and reviewed paper examples. Metadata screening is not exhaustive full-text validation. Historical model outputs are not independent ground truth, and unavailable supplements or access-restricted papers remain unresolved.

## Publication scope

Public material includes source code, documented examples, scoped verification reports, and selected presentation media. Credentials, private document URLs, OAuth tokens, runtime uploads/model outputs, model weights, and complete raw experiment recordings remain local unless explicitly selected for release. Included third-party material is described in [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).
